# 🎮 坦克大战

一个经典的 HTML5 坦克大战游戏，使用纯 JavaScript 编写。

## 🎯 游戏特点

- **单人游戏模式** - 玩家控制蓝色坦克对抗红色敌方坦克
- **积分系统** - 击败敌方坦克获得积分
- **生命系统** - 玩家有3条生命
- **暂停/继续** - 支持游戏暂停功能
- **响应式设计** - 现代化的 UI 界面

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `A` / `←` | 向左移动 |
| `S` / `↓` | 向下移动 |
| `D` / `→` | 向右移动 |
| `空格键` | 发射子弹 |
| `P` | 暂停/继续游戏 |
| `R` | 重新开始游戏 |

## 🎮 游戏规则

1. 使用方向键控制蓝色坦克移动
2. 按空格键发射子弹消灭红色敌方坦克
3. 每消灭一个敌方坦克获得 100 分
4. 被敌方子弹或坦克击中会失去一条生命
5. 生命值为 0 时游戏结束
6. 按下 `R` 键可以重新开始游戏

## 🚀 如何运行

1. 克隆或下载此仓库
2. 用浏览器打开 `index.html` 文件
3. 开始游戏！

## 🛠️ 技术栈

- **HTML5** - 游戏界面结构
- **CSS3** - 游戏样式和动画
- **JavaScript** - 游戏逻辑和交互
- **Canvas API** - 游戏渲染
